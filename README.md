# ai-sdk-threads

> Chat thread and message persistence for the Vercel AI SDK.

**Status: pre-release.** This package is under active development. The 0.0.x
releases reserve the package name while v1 is built. Watch the repo to follow
progress.

Not affiliated with Vercel. "AI SDK" refers to the
[`ai` package](https://ai-sdk.dev).

## Related packages

`ai-threads` and `ai-sdk-persistence` are reserved as aliases of this
